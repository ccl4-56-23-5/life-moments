# 生活点滴双端使用指南

适用版本：Windows 0.3.0-beta.9、Android 0.1.0-beta.5。电脑负责整理与发布，手机和平板负责浏览已备份的照片，并可按需下载原片。首次连接需先把原片备份到百度网盘；仅发布索引不会上传照片。

## 安装与升级

从 [仓库 Releases](https://github.com/ccl4-56-23-5/life-moments/releases) 下载 Windows 安装程序或 Android APK。仓库默认私有，访问者需登录有权限的账号。

Windows 需要 x64 系统、.NET Framework 4.8 和 Microsoft Edge WebView2 Runtime。运行安装程序，选择独立的应用目录，再通过“生活点滴”快捷方式启动。应用目录与原照片目录应分开。卸载会保留原照片及用户整理资料。

Android 需要 Android 9 或更新版本。打开 APK，按系统提示允许当前安装来源，完成侧载。已有版本用相同包名和签名的 APK 覆盖安装，不要先卸载。应用卸载或清除应用数据会删除本机授权、索引和缓存；明确下载到系统相册的照片由系统管理。

## 在电脑整理照片

### 选择照片目录与刷新

打开“设置”，点击“选择照片目录”，选择包含原片的根目录。程序递归读取子目录，先显示列表，再在后台补齐拍摄时间、尺寸和 GPS。照片列表的“刷新”用于重新检查新增、移出及变化的文件。

人物、批注、相册和头像选框保存在独立索引中，不改写原片。切换父目录与子目录时，同一个完整路径的照片保持相同编号。移动文件或更换盘符会改变完整路径，整理资料恢复时应保留原目录结构。

桌面端支持 JPEG，以及内置解码的 HEIF/HEIC。HEIF 显示主图，转换为 8 位 sRGB 预览；不提供 HDR 编辑或多帧播放。

### 浏览与搜索

“照片”页是连续时间线。日、月、年只改变标题分组；年份和月份选择用于定位，不把其他照片从时间线中移除。按拍摄时间或文件名排序，并通过搜索缩小当前照片集合。文件名排序下不使用时间分组。

点击照片打开大图，可缩放、拖动和切换前后照片。关闭大图后回到原来的列表位置。

### 人物与头像

在大图中点击“添加人物”，输入姓名或选择已有人物。关联后，该照片出现在人物详情中。点击人物头像可以进入其照片集合。

在人物页选择“截取头像”，选一张包含此人的照片，拖动选框并调整大小后保存。头像只保存来源照片与选框，不裁掉或覆盖原片。

“编辑标签”支持手写，也可点击已有标签追加；重复选择不会生成重复标签。人物列表可以按标签筛选。当前人物关联由用户手动完成，不会自动检测或识别人脸。

### 相册与批注

在相册页新建相册，通过大图的“加入相册”选择归属。照片可属于多个相册。相册详情可编辑相册批注，大图信息区可编辑照片批注。

相册“管理”显示删除入口。确认删除后，只移除该相册及其批注，原照片、人物关联和照片批注仍保留。相册列表可按创建顺序、名称、照片数量或最近拍摄时间排列。

### 地点与坐标校准

地点页按 GPS 展示照片位置，支持热力与数量聚合。大图中的地点预览可进入对应位置照片，也可校准坐标；图库或单张照片可选择 WGS-84、GCJ-02、BD-09 坐标系。

位置校准写入整理索引，不改写原片 EXIF。在线底图需要网络与有效地图样式；自行构建时在 `config.local.json` 配置 `mapStyleUrl`。未配置在线底图也可显示索引中的位置点。

## 准备百度网盘数据

### 原片目录与索引目录

假设网盘里已有以下结构，文件名仅为示例：

```text
数据备份/
└─ 照片/
   ├─ 2022/
   │  └─ 示例照片.jpg
   └─ 2023/
      └─ 示例合照.heic
```

原片根目录填写 **`/数据备份/照片`**，不用加末尾斜杠，也不用加年份或文件名。索引保留相对路径，例如 `2022/示例照片.jpg`，手机最终读取 `/数据备份/照片/2022/示例照片.jpg`。

索引应发布到同一个百度应用的目录，例如 **`/apps/你的应用名称/生活点滴索引`**。`你的应用名称` 必须换成平台给该应用分配的实际目录名称。原片和索引不必在同一个目录，但对应目录必须在百度授权允许的范围内。

保持本地与网盘的相对子目录及文件名一致。不能只把全部照片压到同一层目录，也不能依靠同名文件自动匹配。手机会按完整路径核对原片，并检查文件大小。

### 电脑连接与发布

1. 在电脑“设置 → 连接百度网盘”填写现有应用的 AppKey、SecretKey 和索引目录。
2. 点击“授权连接”，在打开的系统浏览器中登录保存照片的百度账号，按提示输入授权码并完成授权。
3. 返回应用，确认状态为已连接。
4. 在电脑设置的云端原片根目录填写 `/数据备份/照片`，确保发布索引的路径映射与原片备份一致。
5. 打开“索引同步”。编辑停止约 15 秒后自动发布；点击云朵按钮可立即同步。

每次成功发布保存一个完整索引快照。没有变化的内容不会重复上传，旧版本保留。人物、相册、批注、头像选框和位置校准包含在索引中，AppKey、SecretKey 及授权令牌不包含在内。

“资料发布 → 导出索引”也可生成 JSON 文件，供手机本机导入。这个文件仍需配合已备份原片与有效网盘连接使用。

### 一个百度应用供双端使用

电脑和手机使用同一组 AppKey 与 SecretKey、同一索引目录，不需要给手机再创建第二个百度应用。通常每台设备分别通过原生连接窗口授权；不要手工把令牌放入网页、索引或配置样例。

应用数量限制、授权用户数、目录权限和接口频控仍由百度平台控制。复用一个应用不会绕过这些限制。填写原片目录只告诉客户端去哪里读取，不能扩大平台授予的访问范围。

## 手机首次拉取数据

1. 打开“设置 → 连接百度网盘”，填入电脑所用的同一组 AppKey、SecretKey 和索引目录。
2. 将“已获百度授权的原片目录”填为 `/数据备份/照片`。
3. 点击“授权连接”，在系统浏览器登录相同百度账号并完成授权。
4. 回到手机应用，点击“刷新索引”。授权成功后需要刷新或导入索引，才能绑定当前连接并读取照片。
5. 等待照片列表显示。手机会在满足网络条件时扫描整图库并缓存缩略图，设置页显示进度。

手机会按版本顺序尝试最新的完整索引，校验格式、照片编号及路径后，才替换本机快照。失败时保留原有索引。电脑原片根目录和手机原片根目录不一致时，手机可在校验相对路径后映射到新根目录；这一映射不修改电脑或网盘上的索引。

后续在电脑完成整理并发布，再点击手机“刷新索引”即可更新人物、相册与批注。手机当前没有整理资料编辑或网盘上传、移动、删除功能。

## 手机与平板浏览

小图仅显示照片，不显示人物姓名、小头像或人数角标。打开照片后，人物区域显示姓名与小头像，点击人物可进入其全部照片。

大合照默认分批显示人物，可继续展开，也可搜索姓名。照片信息区同时显示批注、所属相册、拍摄时间、尺寸及云端原片路径。人物头像来源和选框随电脑索引同步；来源照片未备份时，先显示姓名或占位头像。

手机窄屏使用底部导航与展开资料区域。平板宽屏使用侧边导航，大图与照片资料可分栏；横竖屏和分屏按当前可用宽度重新排版。系统栏、挖孔和底部导航区由原生窗口留出安全空间。

### 缩略图缓存与锁屏恢复

启动及载入新索引后自动遍历整图库，只拉取尚未缓存的缩略图。设置中的“缓存全部缩略图”显示已处理数量及失败项，可暂停、继续或重试。

磁盘缩略图最多 1 GiB，并保留至少 128 MiB 可用空间。容量不足时预热停止，已缓存内容保留；正常浏览新照片可能清理较早的缓存。整图库较大时，“扫描完成”不等于每张原片都已成功缓存，应同时查看失败数量或容量提示。

锁屏、切后台或网络中断会取消当前请求并暂停预热。解锁回到应用后，满足网络条件的任务续跑，屏幕附近暂态失败的图片重试。缓存的缩略图可跨应用重启复用；未缓存内容仍需网络。

“仅在 Wi-Fi 下自动加载照片”默认开启。连接手机热点通常仍被系统视为 Wi-Fi，是否产生流量取决于热点来源。关闭此选项后，自动缓存及高清读取可能使用移动网络。

“清理照片缓存”保留索引及明确下载到系统相册的原片，同时暂停自动预热，避免刚清空就立即重下。之后点击缓存入口可恢复。

### 云端高清与明确下载

打开大图先显示缩略图，停留后自动从百度网盘读取高清内容。默认只在 Wi-Fi 下自动读取；使用移动网络时可点击“读取高清图”单独确认。

普通高清浏览只保留在当前浏览内存，不写原片缓存或系统相册。关闭、切换照片、锁屏或系统低内存时释放。显示最长边最高为 4096 px，并根据可用内存缩小；超大原片可能提示下载后使用其他工具查看。

需要保存时，长按小图或大图，在菜单选择“下载到手机相册”。Android 10 及以上保存到系统相册的 `Pictures/生活点滴`；Android 9 由系统文件选择器指定位置。下载保存完整原片字节与原始格式，不使用浏览用的缩小预览替代原片。

高清速度受原片大小、网络、百度限频和手机解码能力影响。后台缓存会为大图让路，已获取的元信息会复用；它们不能保证所有照片立即打开。

## 新 Android 设备复制设置

两台 Android 设备均需使用支持迁移的新版应用，并连到可互访的同一 Wi-Fi。此入口用于 Android 设备之间复制应用设置，不用于复制 Windows 系统设置或 Wi-Fi 密码。

1. 旧设备打开“设置 → 扫描局域网设备 → 旧设备：发送设置”。
2. 新设备打开同一入口，选择“新设备：扫描并接收”，在列表中选择旧设备显示的名称。
3. 扫描不到时，可在新设备手动输入旧设备显示的 `地址:端口`；IPv6 使用 `[地址]:端口`。
4. 比对两台屏幕上的 6 位数字。完全一致时，两边分别确认发送和接收；不一致就取消。
5. 等待接收完成。新设备重新加密保存网盘凭据，随后从云端缓存自己的缩略图。

会话有效三分钟，取消、切后台或完成后关闭发现与连接。传输包含网盘连接、目录、当前授权快照、Wi-Fi 与缓存选项、整理索引、照片排序、分组及相册排序。接收会替换新设备的这些应用设置；旧设备保留原资料。

照片原片、缩略图和设备安全存储密钥不迁移。授权快照不是新增的独立 OAuth 会话，后续若某设备续期失败，应在该设备重新授权。路由器或热点的客户端隔离可能阻止连接；手动输入地址也不能绕过这种隔离。

## 常见问题

| 现象 | 检查与处理 |
| --- | --- |
| 已连接但没有照片 | 先在电脑发布完整索引，再在手机点击“刷新索引”；检查登录账号与索引目录 |
| 最新索引无法使用 | 核对索引是否完整、版本是否兼容；在电脑重新发布，手机失败会保留旧快照 |
| 预览失败或原片未找到 | 在照片信息中查看完整云端路径，检查该路径的原片是否已经备份；补齐后重试 |
| 文件大小不一致 | 网盘文件可能未完成上传或已替换；核对原片及备份版本，重新发布索引 |
| 等待 Wi-Fi | 连接 Wi-Fi，或按需关闭自动加载限制；缓存尚未完成时离线不能看到所有照片 |
| 锁屏后有失败缩略图 | 解锁并回到应用，等待自动恢复；必要时在设置重试失败项 |
| 点击失败照片仍闪退 | 更新到最新版，记录 Android、WebView 版本、网络类型、页面与完整错误；交给维护者复现 |
| 高清仍需等待 | 查看原片大小和网络，先暂停全图库缓存测试；超大原片用长按下载后查看 |
| 地图空白 | 检查网络与地图配置；没有底图时索引中的坐标和位置点仍可用 |
| 局域网找不到设备 | 双方打开对应迁移窗口、保持解锁、同一 Wi-Fi；试手动地址，检查客户端隔离 |
| 新设备网盘授权过期 | 使用原生连接窗口重新授权，再刷新索引 |
| APK 无法覆盖安装 | 检查包名与签名；作者包和其他机器自行编译的 debug 包可能不同，先保全资料再处理 |

源码备份不能代替照片备份。Windows 整理资料位于 `%LOCALAPPDATA%\LifeMoments`，应与原片目录一起自行备份；授权凭据还受当前 Windows 用户加密保护。Android 本机资料处于应用私有目录，优先通过应用迁移入口或重新从云端连接与拉取。
