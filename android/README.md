# 生活点滴 Android 0.1.0-beta.5

Android 9 及以上的个人测试版，支持手机和平板。电脑整理人物、相册、批注与地点，Android 校验并读取百度网盘索引，按完整路径浏览已备份照片。

安装包为 `artifacts/生活点滴-安卓-0.1.0-beta.5.apk`，发布后也可从 [GitHub Releases](https://github.com/ccl4-56-23-5/life-moments/releases) 下载。私有仓库需要访问权限。完整双端操作见 [使用指南](../docs/使用指南.md)，构建及资料备份见 [开发与维护](../docs/开发与维护.md)，变化见 [版本记录](../docs/版本记录.md)。离线拉取教程为 `artifacts/手机端拉取数据教程.html`，原生实现说明见 [手机端维护文档](手机端维护文档.md)。

## 功能与数据约定

- 连续时间线、日月年分组、日期定位、搜索、照片排序和相册排序。
- 小图只显示照片；展开界面显示人物姓名和小头像，点击人物查看其照片。大合照人物分批展开并支持姓名搜索。
- 启动后扫描整图库并缓存尚未缓存的缩略图，磁盘上限 1 GiB，并保留至少 128 MiB 空闲空间。锁屏暂停，回到应用后续跑与重试暂态失败。
- 高清图从云端读取，只在当前浏览内存显示。关闭或切换后释放；最长边最高 4096 px，按可用内存缩小。普通浏览不保存原片文件。
- 小图或大图长按选择下载，保存完整原片到系统相册；Android 9 使用系统文件选择器。
- 平板侧边导航与宽屏资料分栏，横竖屏和分屏按当前宽度适配。原生系统安全区、品牌开屏与缓动遵循系统减少动画设置。
- 原生连接、下载和迁移窗口使用与网页一致的浅灰背景、圆角卡片、字体与蓝色控件，适配横屏和键盘弹出。
- 同一局域网扫描旧 Android 设备，双方核对验证码并确认后加密复制应用设置、网盘连接和图库索引，新设备重新加密凭据。

电脑和手机复用同一百度应用。索引目录通常为 `/apps/你的应用名称/生活点滴索引`；网盘原片位于 `数据备份/照片` 时，手机原片根目录填写 `/数据备份/照片`，保留相对子目录。填写目录不会增加平台授权范围。授权完成后还需“刷新索引”或导入索引。

人物、相册和批注来自电脑整理，当前没有手机编辑或网盘上传、移动、删除接口。界面不显示“只读”徽标。普通高清浏览与明确下载分开；照片原片、缩略图和 Keystore 密钥不参与局域网迁移。

## 构建与验证

从仓库根目录安装 Python/Pillow，准备 JDK 17+、Android SDK 35 和 Build Tools 35，并配置 `JAVA_HOME` 与 `ANDROID_HOME`：

```powershell
python -m pip install -r requirements.txt
& .\android\build.ps1 -SdkPath $env:ANDROID_HOME -JdkPath $env:JAVA_HOME -PythonPath python
```

脚本生成资源，使用 Gradle 8.13 和 Android Gradle Plugin 8.13.2 执行 `assembleDebug`、`lintDebug`。首次构建联网恢复依赖；缓存齐全时可加 `-Offline`。在线地图在根目录 `config.local.json` 的 `mapStyleUrl` 配置，样例见 `config.example.json`；空配置使用空白底图与已有位置点。演示素材为程序生成的 35 张风景插画。

界面回归与 JVM 检查方法见 [开发与维护](../docs/开发与维护.md#回归验证)。本版构建与 Lint 已通过，手机/平板合成界面回归通过；真实生产代码的 JVM fixtures 共通过 97 项检查：缓存调度 11、密码协议 19、socket 协议 13、迁移数据与索引 54。浏览器高清和地图使用接口替身，Android Keystore、系统 NSD、两台实体设备迁移、锁屏整机体验与真实百度速度仍待设备验证。

APK 使用 debug 签名供个人侧载测试。覆盖升级须保持包名 `com.lifemoments.reader` 与相同签名；不同电脑自行构建的 debug 包可能无法直接覆盖。正式发布需配置发布签名和平台审核。不要先卸载来解决升级问题，以免删除本机授权、索引和缓存。
