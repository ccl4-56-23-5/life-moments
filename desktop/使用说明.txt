生活点滴 Windows 0.3.0-beta.9（Beta 测试版）

下载安装
从 https://github.com/ccl4-56-23-5/life-moments/releases 下载对应版本安装程序。
私有仓库需要登录有访问权限的 GitHub 账号。
运行环境：Windows x64、.NET Framework 4.8、Microsoft Edge WebView2 Runtime。
应用目录与原片目录分开。安装完成后从“生活点滴”快捷方式启动。

照片目录与浏览
首次启动默认使用系统“图片”目录，可在设置中选择自己的照片根目录。
递归读取子目录；照片目录内不写入索引、缓存或转换文件。
列表先显示缓存，后台补齐 EXIF 时间、尺寸和 GPS；“刷新”检查目录变化。
照片编号由规范化完整路径生成，父子目录切换保持同一编号；移动文件或更换盘符会改变编号。
连续时间线支持日、月、年标题分组、日期定位、搜索和排序；分组不隐藏其他日期的照片。
按文件名排序时不作时间分组。点击照片打开大图，支持缩放、拖动和前后切换。
保留横图、竖图与全景的原始比例。缩略图保存于独立用户缓存。
内置 HEIF/HEIC 解码，无需另装 HEIF/HEVC 扩展。大图显示主图的 8 位 sRGB PNG 缓存，不提供 HDR 编辑或多帧播放。

人物、相册与地点
在大图中手动添加人物；点击人物进入其照片集合。
人物页可从来源照片裁剪头像，编辑标签或点击已有标签追加，重复选择自动去重。
头像保存来源照片编号和选框，不修改原片。人物列表可以按标签筛选。
在相册页创建相册，大图中加入相册；照片可属于多个相册。
照片批注和相册批注独立保存。相册管理删除只移除相册及相册批注，保留照片与其他标注。
相册支持创建顺序、名称、照片数量和最近拍摄时间排序。
地点页显示 GPS、热力与位置聚合；大图可进入地点页并校准坐标。
坐标校准与 WGS-84、GCJ-02、BD-09 选择写入整理索引，不修改原片 EXIF。
在线地图需要网络与有效样式。自行构建时通过 config.local.json 的 mapStyleUrl 配置；未配置仍显示位置点。

百度网盘与 Android
电脑和 Android 手机、平板复用同一百度应用的 AppKey、SecretKey 和索引目录，不需要再创建第二个应用。
设置→连接百度网盘：填写自己的凭据及 /apps/你的应用名称/生活点滴索引，按提示在系统浏览器授权。
AppKey、SecretKey 和索引目录草稿用当前 Windows 用户加密保存；失败或取消不覆盖已有有效授权。
网盘原片位于“数据备份/照片”时，云端原片根目录填写 /数据备份/照片；保留相对子目录和文件名。
索引目录与原片目录用途不同。填写原片目录不能增加百度授权范围或接口配额。
打开“索引同步”后，编辑停止约 15 秒自动发布；云朵按钮可立即同步。
云端保存完整版本索引，重复无变化的内容不上传，旧版本保留。
索引包含人物、相册、批注、头像选框、位置校准和原片云端路径，不含密钥或令牌。
“资料发布”可导出索引。原片上传由现有备份工具负责，仅发布索引不会上传照片。
Android 0.1.0-beta.5 已支持读取同一索引、人物头像、平板布局、全图库缩略图缓存、内存高清浏览与长按下载。
手机连接授权后点击“刷新索引”；原片根目录同样填写 /数据备份/照片。
新 Android 设备可通过局域网入口接收旧设备设置，双方核对六位验证码并确认后加密传输。
手机当前浏览整理结果，人物、相册及批注仍在电脑编辑。

资料、升级与维护
索引、设置、缓存和 WebView2 用户资料位于 %LOCALAPPDATA%\LifeMoments。
百度凭据用 Windows 当前用户加密，不进入网页、导出索引或安装包。
卸载保留原照片及用户整理资料。源码备份不能代替原片和整理资料备份。
同一路径安装新版覆盖程序文件；备份索引时保留原照片完整路径与用户资料目录。
品牌开屏、页面缓动遵循系统动画偏好；慢加载显示真实状态。

源码说明
完整双端操作：docs/使用指南.md；构建与资料维护：docs/开发与维护.md；更新记录：docs/版本记录.md。
从仓库根目录执行 desktop/build.ps1 -PythonPath python；首次构建联网恢复固定版本依赖，已恢复时可加 -Offline。
构建需要 Python 与 Pillow；依赖含 WebView2 SDK 1.0.4258.31、Magick.NET 14.17.2、MapLibre 与 Lucide。
配置样例 config.example.json 可复制为被 Git 忽略的 config.local.json，填写自己的地图样式 URL。
安装包保留第三方许可与地图来源署名；源码演示素材为程序生成的 35 张风景插画。
