# 生活点滴 Windows 0.3.0-beta.9：架构与构建

Windows 端使用 WinForms 与 WebView2 读取本地原片，保存人物、相册、批注与位置校准，并向百度网盘发布完整整理索引。Android 0.1.0-beta.5 已接入同一索引，浏览与下载已备份的原片。双端均保持 Beta 标识。

双端操作见 [使用指南](../docs/使用指南.md)，通用构建及资料备份见 [开发与维护](../docs/开发与维护.md)，版本变化见 [版本记录](../docs/版本记录.md)。本文说明 Windows 宿主及桌面界面的维护边界。

## 代码与数据位置

| 文件 | 职责 |
| --- | --- |
| `DesktopApp.cs` | 窗口、目录会话、网页消息、资源请求、同步调度 |
| `PhotoLibrary.cs` | 目录发现、路径身份、元信息缓存、整理索引与导出 |
| `JpegMetadata.cs`、`HeifDecoder.cs` | JPEG EXIF、HEIF 元信息与预览解码 |
| `BaiduSync.cs` | 原生 OAuth、加密凭据、完整索引分片上传 |
| `LoadingScreen.cs` | 网页前的原生开屏与揭示衔接 |
| `Installer.cs` | 安装、卸载、快捷方式与 Windows 安装记录 |
| `build_frontend.py`、`frontend.js/css`、`tag_editor.js/css` | 模板生成、桌面交互、人物标签扩展 |
| `DesktopTests.cs` 与各功能测试类 | 独立资料目录的原生与网页回归 |

默认照片来源为系统“图片”目录，用户通过设置选择实际照片根目录。安装程序默认使用当前用户的应用目录，支持选择其他目录；不能安装到原片目录。用户资料位于 `%LOCALAPPDATA%\LifeMoments`：

- `library-index-v2.json` 共用人物、相册、批注、头像与位置校准。
- `settings.json` 保存来源目录等设置；目录的云端映射独立保存。
- `photo-cache-v2.json` 保存增量元信息，`thumbnails` 和 `rendered` 保存显示缓存。
- 百度凭据以 Windows 当前用户 DPAPI 加密；WebView2 用户资料也位于独立用户资料目录。

原照片目录保持不改写。卸载保留用户整理资料，源码备份不代替原片及资料备份。

## 照片身份与目录会话

照片 ID 取规范化完整路径 SHA-256 的低 48 位，切换父子目录仍保持同一编号。移动文件或更换盘符会产生新路径身份；跨设备内容指纹、编号别名与迁移合并尚未实现。

首次打开迁移可识别根目录的旧 `indexes/*.json`，映射人物关联、相册成员、头像来源及位置覆盖，保留旧文件。未知旧根目录需要其来源路径，不猜测编号。

网页保存消息携带目录会话令牌，原生层拒绝旧页面的保存，防止切换目录时覆盖新会话。刷新后移出目录的照片不显示，既有标注不自动删除。目录扫描跳过重解析点，视频不进入照片列表。

## 启动、刷新与图片服务

WebView2 初始化与目录发现同时进行，先显示缓存或文件名日期，再后台读取 JPEG 标记与 TIFF EXIF。读取元信息不解码 JPEG 像素；GPS 保持 `[经度, 纬度]` 顺序并保留坐标系设置。元信息缓存以完整路径、文件长度与 UTC 修改时间判定变化。

缓存读取、旧索引迁移、照片预载序列化在后台按顺序执行，避免共享序列化器的竞争。目录周期与网页导航检查关闭状态和 generation，旧周期不能隐藏新加载界面。EXIF 后台扫描在网页 ready 后开始，不等待装饰动画。

缩略图按界面请求生成，最多两个并发任务。照片 ID 字典定位原片，合并在途图片请求，缓存读取不占解码队列。JPEG 大图读取原片，HEIF 大图通过独立解码队列。刷新、窗口变化与目录切换保留可恢复的浏览锚点。

## 连续时间线与整理界面

日、月、年只改变标题分组，年月控件用于定位；时间线保留当前集合中的全部照片。搜索、人物和相册限定各自集合。布局按原始宽高比计算等高行，尾行靠左，不裁切横图、竖图或全景。

照片排序支持拍摄时间与文件名升降序。按文件名时关闭时间分组，回到时间排序可继续分组。相册支持创建顺序、名称、照片数量和最近拍摄时间排序；排序使用副本，不改变相册存储顺序，避免批注及加入相册指向错误对象。相册删除修正选中下标，仅移除相册及其批注。

人物由用户手动关联。头像保存来源照片与比例选框，不修改原片。标签编辑保留手写分隔输入，已有标签从人物 profiles 去重汇总；点击只追加缺少的项，保存仍使用现有 `profiles[name].tags` 字段。人物标签、照片及相册批注均进入整理索引。

照片页面复用应用外壳及最多一份 DOM。索引、照片元信息、搜索、排序、分组与宽度变化使缓存失效；照片行使用 `content-visibility:auto` 减少屏幕外绘制。人物头像仅在来源或选框变化后重画，内存最多复用 64 个头像画布。性能回归保留渲染时间和下一帧时间，不把特定图库的结果写成普遍保证。

## 品牌与动画

`create_brand_assets.py` 生成统一的蓝青“照片水滴”SVG、PNG 与 ICO；程序、快捷方式和界面使用同一几何。快捷方式引用独立图标文件，减少旧 exe 图标缓存影响。

`LoadingScreen.cs` 使用原生双缓冲绘制抛入小球、三次递减弹跳、Logo 展开与退出。较慢加载停留 Logo 并显示真实状态，切目录使用静态周期。完成、替换周期或关闭时释放等待并停止计时器；遵循 Windows 客户区动画偏好。

原生退出触发前端 `desktopReveal`。页面身份变化后播放约 230–260 ms 的 `cubic-bezier(.22,1,.36,1)` 缓动，每次取消上一批动画。最多处理少量当前可见元素，长时间线和 sticky 祖先不变换；刷新、筛选、分组与后台数据更新不重播页面过渡。动画结束不留内联样式，并遵循减少动画设置。

## HEIF/HEIC 与在线地图

HEIF 使用 NuGet 官方 Magick.NET-Q8-x64 与 Core 14.17.2，Windows x64 原生库随安装包分发。初始化按需执行，JPEG 目录发现不加载解码器。元信息通过 Ping 与 EXIF 读取，尺寸和方向避免重复旋转。

缩略图为不超过 480 px 的 JPEG，完整尺寸显示缓存为 PNG，转换为 8 位 sRGB。缓存身份含路径、长度、UTC 修改时间与解码版本，并原子写入；头像和云端映射保持原片编号与原扩展名。显示主图，不展开多帧、深度图或 HDR 增益图。修改色彩或解码算法时升级显示缓存版本。

地点页使用 MapLibre，展示热力、聚合和照片位置。根目录 `config.local.json` 的 `mapStyleUrl` 在构建时提供在线样式；空样式使用空白底图并保留位置点。配置样例不含在线密钥。坐标校准与坐标系选择写入整理索引，原片 EXIF 不变。在线资源保留 MapTiler 和 OpenStreetMap 署名。

## 百度授权与索引发布

电脑和 Android 可共用同一个百度应用的 AppKey、SecretKey 与索引目录，分别完成原生设备授权。应用数量、授权人数、目录范围与接口配额仍由百度决定。原片目录可映射为 `/数据备份/照片`，索引目录通常为 `/apps/你的应用名称/生活点滴索引`，两者分开配置。

凭据输入使用原生窗口，SecretKey 掩码，密钥和令牌不经过网页。草稿与有效连接分开保存，以 Windows DPAPI 保护；失败或取消不替换已有授权。OAuth HTTP 400 先解析结构化错误，再处理 `authorization_pending` 与 `slow_down`。其他状态、非 JSON、拒绝、过期或无效令牌仍失败，错误不暴露原始响应与令牌。

索引上传遵循预创建、4 MiB 分片、分片 MD5 校验和创建完整文件。响应按 UTF-8 字节解析并剥离 BOM，兼容 `charset=utf8`；错误指出上传阶段。用户关闭同步开关取消未完成发布，失败保留本地资料。

编辑停止约 15 秒自动发布；点击云朵可立即发布。内容摘要忽略发布时间，无变化不重复上传；每次发布使用不可变版本文件名，成功后记录同步时间，期间的新编辑继续排队。

云端 schemaVersion 2 包含图库身份、原片根目录、照片相对与完整云端路径，以及整理索引；导出排除本机原片路径、网页图片 URL 与凭据。Android 已支持列出候选索引、校验后原子替换，并按完整路径读取已备份原片。当前只有电脑写入整理资料，没有多台电脑冲突合并或自动版本清理。照片原片不传入 `BaiduSync` 上传模块。

## 构建

从仓库根目录执行：

```powershell
python -m venv .venv
$pythonPath = (Resolve-Path .\.venv\Scripts\python.exe).Path
& $pythonPath -m pip install -r requirements.txt
Copy-Item .\config.example.json .\config.local.json
& .\desktop\build.ps1 -PythonPath $pythonPath
```

需要 Windows x64、.NET Framework 4.8 与系统 C# 编译器；运行需要 WebView2 Runtime。脚本先恢复固定版本依赖、生成前端，然后编译 x64 宿主和安装程序。首次联网下载；提前恢复后可传 `-Offline`。恢复脚本固定 NuGet 包与 Lucide 版本并验证 SHA-256，依赖下载至被 Git 忽略的 `desktop/vendor`。

当前引用 WebView2 SDK 1.0.4258.31、Magick.NET 14.17.2 与系统 netstandard.dll。托管库、原生 DLL 和上游许可随包分发。程序输出在 `desktop/out`，安装程序为 `desktop/artifacts/生活点滴-安装程序-0.3.0-beta.9.exe`。

前端由 `preview` 共用模板、桌面扩展与 `build_frontend.py` 生成，配置与合成演示素材由脚本管理。修改源模板或生成器后重新生成，不只修改构建输出。源码演示素材为程序生成的 35 张风景插画，不使用用户原片或精确轨迹。

## 验证与交付

原生回归使用独立测试资料目录和照片夹具：

```powershell
$testDataPath = Join-Path $env:TEMP ('life-moments-test-' + [Guid]::NewGuid().ToString('N'))
$photoFixturePath = (Resolve-Path .\test-photos).Path
& .\desktop\out\生活点滴.exe --self-test --test-data $testDataPath --source $photoFixturePath
```

先准备独立的 `test-photos` 夹具目录，或将变量改为自己的测试夹具路径；`--test-data` 不能使用实际用户资料。检查 PASS 记录、首帧截图、路径身份、标注保留、刷新、旧会话拒绝、模拟授权与上传。测试人物、相册、截图及索引留在隔离目录，不上传真实个人资料。

`BaiduAuthorizationTests` 以无浏览器与无真实等待的模拟接口检查等待、降速、成功、保存、拒绝、取消和超时。`BaiduUploadResponseTests` 覆盖 UTF-8 别名与 BOM、完整发布、摘要去重、MD5 错误、HTML 网关页和非 OAuth HTTP 400。`DesktopTagTests` 覆盖点击已有标签、手写保留、去重、键盘、取消、持久化及筛选。开屏回归验证完成、替换与释放等待；首帧报告区分网页 ready 与揭示时间。

Beta 9 已完成构建；Android Beta 5 的构建、Lint、合成手机/平板界面与 97 项 JVM 检查已通过。真实账号授权、实际发布和新版实体设备端到端读取仍需对应账号与设备验证，模拟检查不能代替。HEIF 回归应使用可公开的独立夹具核对元信息、缩略图、方向、完整 PNG、人物关联与头像裁剪。

发布时同步版本、安装记录、使用说明与根文档，记录 SHA-256。安装包使用 Release 附件，源码提交排除个人原片、索引、凭据、本机构建缓存与签名。反馈先记录应用/系统/WebView 版本、完整错误、网络和复现步骤，并区分本地解码、索引发布、手机缩略图及高清读取。
