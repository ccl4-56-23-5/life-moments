# 生活点滴

生活点滴用 Windows 电脑整理照片、人物、相册、批注和地点，再通过百度网盘把整理结果带到 Android 手机和平板。电脑读取本地原片，手机按完整云端路径读取已备份的照片；原片备份由现有备份工具负责。

当前版本为 **Windows 0.3.0-beta.9** 和 **Android 0.1.0-beta.5**，均为个人测试版。

## 构建与开始使用

当前公开仓库提供双端源码、配置样例和使用文档。需要安装时，可按 [Windows 构建说明](desktop/架构与构建说明.md) 或 [Android 构建说明](android/README.md) 自行构建。

| 平台 | 运行环境 |
| --- | --- |
| Windows | Windows x64、.NET Framework 4.8、Microsoft Edge WebView2 Runtime |
| Android | Android 9 或更新版本，支持手机和平板 |

首次使用先在电脑设置中选择照片目录，整理并发布索引；再在手机设置中连接同一个百度应用，填写索引目录和原片根目录，点击“刷新索引”。例如，网盘中的 `数据备份/照片` 应填写为 `/数据备份/照片`。

已有 Android 版本请使用同一签名的安装包覆盖升级，保留网盘授权、索引与缩略图。不要为了升级先卸载；自行编译的 debug 包可能使用不同签名。

详细操作见 [使用指南](docs/使用指南.md)，构建与数据维护见 [开发与维护](docs/开发与维护.md)，版本变化见 [版本记录](docs/版本记录.md)。

## 双端功能

| 功能 | Windows 电脑 | Android 手机和平板 |
| --- | --- | --- |
| 照片 | 连续时间线、日月年分组、日期定位、搜索、排序、大图缩放 | 相同浏览方式，按屏幕宽度调整布局 |
| 人物 | 手动关联人物、裁剪头像、编辑标签、按标签筛选 | 读取电脑的人物与头像，按人物查看照片；小图不显示人物标记 |
| 相册和批注 | 创建与管理相册，编辑照片及相册批注 | 浏览已同步的相册与批注 |
| 地点 | 读取 GPS，查看位置照片，校准坐标与坐标系 | 显示电脑同步的位置与校准结果 |
| 图片读取 | 本地原片与独立缩略图缓存，内置 HEIF/HEIC 解码 | 启动后缓存整图库缩略图；打开大图从云端读取，普通浏览只使用内存 |
| 保存照片 | 保持原照片目录不变 | 长按小图或大图，明确下载完整原片到手机 |
| 新设备 | 重新连接网盘 | 扫描同一局域网的旧 Android 设备，双方确认后加密复制应用设置与连接 |

人物来自电脑端的手动整理，当前没有自动识别人脸或手机编辑人物、相册与批注的功能。多人合照在手机展开界面分批显示头像，并可按姓名搜索。平板使用侧边导航；宽屏大图可与照片资料分栏显示。

## 百度网盘数据流程

电脑和手机填写同一个百度应用的 AppKey 与 SecretKey，无需为手机另建一个应用。各端可分别授权；新 Android 设备也可接收旧设备的授权快照。复用应用不会增加百度的授权人数、接口配额或目录权限。

| 数据 | 保存位置 | 处理方式 |
| --- | --- | --- |
| 原片 | 用户本地照片目录，以及已备份的网盘目录 | 原片备份工具负责上传；本项目不自动上传原片 |
| 整理索引 | 电脑用户资料目录、网盘应用目录、手机本机快照 | 电脑发布完整版本，手机校验并拉取 |
| 网盘凭据 | 各设备的加密安全存储 | 不进入网页、导出索引或 Git 仓库 |
| 手机缩略图 | 应用私有缓存 | 最多 1 GiB，容量或剩余空间不足时停止全图库预热 |
| 手机高清图 | 当前浏览内存 | 关闭或切换照片后释放；长按下载才保存文件 |

索引目录通常是 `/apps/你的应用名称/生活点滴索引`，原片目录可为 `/数据备份/照片`。两者用途不同，手机读取时保留照片的相对子目录。

锁屏、切后台或网络中断会暂停缩略图请求；解锁回到应用后继续缓存并重试暂态失败。实际高清速度受网络、原片大小与百度接口状态影响。新版本的真实设备锁屏恢复、两台设备发现与迁移，仍需安装后验证。

## 源码与构建

仓库目录：

```text
desktop/       Windows 宿主、界面扩展、安装程序和原生回归
android/       Android 原生宿主、移动界面、构建和测试
preview/       双端共用界面模板、地图资源和合成演示素材
scripts/       固定版本依赖恢复等开发脚本
docs/          双端使用、维护和版本说明
```

构建工具需要 Python 和 Pillow；Windows 使用 .NET Framework 编译器与 WebView2 Runtime，Android 使用 JDK 17+ 与 SDK 35。首次构建下载固定版本依赖，准备齐全后两端均可使用 `-Offline` 选项。完整命令见 [开发与维护](docs/开发与维护.md#构建环境与依赖)。

将 `config.example.json` 复制为被 Git 忽略的 `config.local.json`，可在 `mapStyleUrl` 中填写自己的在线地图样式 URL。未配置时使用空白底图，保留照片位置点。网盘凭据在运行时由各端原生连接窗口填写。

仓库保存双端源码、配置样例、合成演示素材和文档。个人原片、真实索引、授权凭据、个人截图、设备资料与本机构建缓存不属于源码备份。恢复源码后，仍需自行保管照片与整理资料。

第三方依赖的许可随相应资源和安装包保留，包括 WebView2、Magick.NET、MapLibre 与 Lucide；在线地图保留 MapTiler 和 OpenStreetMap 署名。
